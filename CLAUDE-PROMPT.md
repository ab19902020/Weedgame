# Green County — next playable Android milestone

Work directly in this repository as the gameplay and graphics engineer. Start by running the existing v0.3 game and inspecting the save, simulation, rendering and Android launch paths. Implement and test a playable upgrade in this session. Deliver the changed source and a signed development APK with a higher version code. Keep the existing application ID and support existing saves. Use an authorised signing key supplied outside Git if available. Explain any device or signature limitation.

Build one memorable first ten minutes. Cal and Leon start with one Woodley lock-up, two mates and a battered hatchback. An incoming phone call gives one brother a reason to drive towards Earley while the other tends the garage. Let the player swap between them, fulfil the order and spend the proceeds on a visible improvement. Keep the entire Berkshire map freely accessible from the beginning.

1. Make Woodley convincing at street level. Review concept-art/05 through 07. The player rejected the earlier comic treatment; the final visual direction is still open. Use grounded British materials, readable dusk lighting, garage shutters, shopfronts, UK signs, coherent scale, animated walking and a recognisable hatchback. Prioritise a stable 30 fps on an Honor Magic 6 Pro, with resolution scaling and a lighter graphics setting. Record measured performance where possible.
2. Make driving and navigation dependable. Implement acceleration, braking, reverse, steering, follow camera and building collisions. Check spawn points, garage doors and road connectivity. Retain OSM attribution. Verify Cemetery Junction, Reading town centre, Earley, Woodley, Winnersh, Bracknell, A329 and A329(M) against the imported coverage. Mark gaps honestly. Make destination selection, waypoints and route feedback usable with thumbs in landscape.
3. Connect the existing systems. Crew should accompany the active brother. Rival sales should trigger a readable fictional encounter; winning a block should change its map overlay and make subsequent sales there safe. Preserve crop timers, strain names, economy, car upgrades, ownership and brother positions through backgrounding and relaunch. Give the player feedback on what each lighting, water or room upgrade changed.
4. Keep the story easy to extend. Give each brother a distinct voice in the opening dialogue. Store call lines with speaker and stable audio IDs so Fish Audio or ElevenLabs clips can be added later. Use subtitles now. Keep API credentials outside the client and repository.
5. Test a fresh game and a migrated v0.3 save. Test entering/exiting a car, brother swaps, crew following, rival versus owned sales, visiting the workshop, finishing a call order, buying an upgrade and resuming after closing the app. Report what ran on hardware, emulator or only in a scripted test. Include build commands and the APK location.

If the full milestone exceeds one session, finish and verify the opening garage-to-delivery loop first. Keep the game playable at each commit. Longer-term goals include police pursuits, rival attempts to retake blocks, staffed warehouses, outdoor expansion, bulk orders and broader vehicle customisation.
