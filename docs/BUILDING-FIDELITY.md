# Berkshire building fidelity — 27 November 2026
The existing world uses OSM building polygons and measured Environment Agency DSM/DTM roofs. The last measured-building report covers 84,507 of 86,399 footprints. This is a geometry source, not street photography.
This pass keeps measured roof silhouettes at distant LOD, stops shrinking measured ridge height when a roof rectangle is fitted to the footprint, improves street-facing front selection, blanks inferred party walls, reduces arbitrary bay windows and porch roofs, and groups inferred brick and roof styles by local frontage. No copyrighted street-view texture is copied.
The OSM build previously read material/colour tags but discarded them. The optional bStyle array now carries supported material categories into the shader on a world rebuild; existing tiles use inferred styles. Exact paint colour, individual window layouts, extensions, gardens, driveway materials and signs not in the map data remain unverified. The finish codes are not a substitute for a licensed survey.
Validation: run npm test, npm run build, shadercheck and Android screenshots at both near/far LOD. To use observed material tags, rebuild world from the OSM extract and preserve LiDAR records with carry_lidar.py or rerun lidar_buildings.py. Do not treat the inferred look as a surveyed replica. No binary world files or APK were rebuilt in this pass.
