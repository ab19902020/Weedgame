# Green County radio
Extract the supplied radio asset pack at repo root (www/radio/*.m4a). Audio is streamed locally from the APK; no external network required. Music: United Road FM (8 tracks); Green County Talk (1 podcast); off. D-pad Left / touchscreen Radio / keyboard U opens wheel. Cross confirms; Circle closes; D-pad or right stick selects; L1/R1 skip in wheel. Home radio is on the TV stand, use Triangle nearby. Separate station selection per vehicle/home, shared station resume positions during session, one audio element. Radio tracks are user-supplied; confirm redistribution rights for the podcast before public release. Audio files are not in this code commit.
The wheel pauses world simulation while open but audio continues; closing clears held controls. More audio can be added by extending STATIONS and placing corresponding AAC files in www/radio. The asset pack contains 9 files (8 unique songs and one podcast); the two National Anthem uploads were byte-identical.
