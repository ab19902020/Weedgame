The console contains offline HTML builds of NarcoLord2026 (79c6395) and Manchester-United-manager- (0779800), compressed with gzip. Each opens inside the living-room console and retains its own save system.

To package the television channel, fetch the branches of the private South-park- repository into a local clone, then run `python3 tools/home/episodes.py /path/to/South-park-` before building. The installer verifies each original MP4 against its source Git blob. The home TV preview includes all ten exports.
